# Background music

Put music files here (.mp3, .m4a, .wav, .flac, .ogg, .opus). Each clip gets a random track,
starting at the track's energetic part.

**Credit line:** next to `Some Track.mp3`, add `Some Track.txt` containing the credit exactly as the
source asks for it. It goes into the clip's description automatically. Without it, the file name is used.

Free sources that allow use in monetized YouTube videos:

- **NCS (NoCopyrightSounds)**: ncs.io. Free on YouTube; they require the artist and song credit in the description.
- **YouTube Audio Library**: YouTube Studio → Audio Library. Some tracks need attribution (shown there).

Music files are not committed to git (they are listed in `.gitignore`).
Don't use popular songs: Content ID will claim them, and Shorts over 1 minute with a claim get blocked.
